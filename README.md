## Overview

This repository contains a graduate-level cybersecurity governance
project developed as part of the **Security Policies and Risk
Management** course at Ontario Tech University.

The project presents a comprehensive set of enterprise security policies
for a fictional Canadian financial institution, **Meridian Trust
Financial Group**, implementing an **Employee Productivity and Activity
Monitoring (EPAM)** system.

The objective was to develop security governance policies that balance
cybersecurity, privacy, regulatory compliance, and operational
requirements for a hybrid workforce.

------------------------------------------------------------------------

## Project Objectives

-   Develop enterprise security policies for employee monitoring
-   Reduce insider threat and fraud risk
-   Protect employee privacy
-   Support secure hybrid work environments
-   Align organizational policies with Canadian regulations and
    cybersecurity best practices
